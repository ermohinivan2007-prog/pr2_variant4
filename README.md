# Практическая работа №2. Вариант №4

## Описание проекта
Веб-приложение с HTTP API для асинхронного вычисления хеш-сумм файлов по алгоритму SHA-256. 
В качестве вычислительной задачи реализована утилита командной строки, которая вычисляет хеш файла и сохраняет результат в JSON. 
HTTP-сервер обрабатывает запросы, проверяет авторизацию (Basic Auth) и вызывает утилиту через `subprocess`.

## Структура проекта
* `src/cli.py` — утилита командной строки (вычисление SHA-256).
* `src/auth.py` — модуль проверки Basic Auth (RFC 7617).
* `src/server.py` — HTTP API сервер на базе `BaseHTTPRequestHandler`.
* `tests/test_api.py` — MBT-тесты (Model-Based Testing) на базе `hypothesis`.
* `examples/` — примеры входных файлов для демонстрации.

## Требования
* Python 3.9+
* Зависимости из `requirements.txt` (устанавливаются в виртуальное окружение).
